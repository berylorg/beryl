# Ordinary Running-Home Recovery

The controlling contract is the app's
[ordinary running-home recovery ownership](../../crates/beryl-app/doc/design-shell-lifecycle.md#ordinary-running-home-recovery-ownership).
This record preserves qualification lessons; it does not define recovery authority.

## Custody And Native Qualification Lessons

The interrupted lifecycle driver could not be mounted unchanged for an ordinary failed home.
Its request-specific guards rejected independent attempts, and its threadless path assumed clean
resident retirement. The shared driver now carries a distinct ordinary attempt identity and
retires the failed resident set even when no selected resident exists. Ordinary publication proves
the unchanged Running session rather than writing an Exit-to-Running resume.

Cancelled fresh construction must return original failed resident and graph-retirement custody
after joining the candidate's workers. Treating that return as a clean resident capture would
discard protected edits or misrepresent uncertain outcomes. Partial attachment cleanup disposes
only the fresh adopted mounts; unadopted original residents remain protected.

Native editor geometry alone did not prove that the asynchronous input position proof was ready.
Dirty-edit fixtures now wait for resident flights and realization to settle before their first edit.
Preservation compares text, history, frontier, selection and editor identity while allowing the
required fresh service/session binding and publication checkpoint.

A reopening worker temporarily owns the service graph. The retry fixture must assert worker
custody and rejection of the old dispatch permit while reopening is blocked; querying GUI service
ownership there is invalid. The final Exit of a recovered fixture can also require a native running
threads confirmation. Its helper checks the exact fixture window, current child process, popup owner
and title before confirming, so the fixture handles its own dialog without targeting another Beryl.

These lessons are exercised by the mounted ordinary recovery tests and affected lifecycle tests.
