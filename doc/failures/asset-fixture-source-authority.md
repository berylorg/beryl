# Asset Fixture Source Authority

Composed asset qualification exposed outdated fixture preconditions rather than image-byte or
resource-owner defects. Correct the fixture's real authority and source lifecycle before changing
production checks or weakening assertions.

The active-steering fixture admitted a lifecycle-only session, then tried initial checked-user
publication without an enrolled Activity source. Both text-only and repeated-image cases failed
before image work with `Activation(Publication(ActivityAuthorityUnavailable))`. The fixture now
retains the existing runtime-interest harness, waits for its exact process generation, enrolls
the activated thread/turn through the real bounded Activity path, and publishes the session with
that interest. Projection retirement precedes harness shutdown/join. No publication check is
bypassed; see the [fixture support](../../crates/beryl-app/tests/unit/active_steering_delivery/support/runtime.rs).

Mounted image fixtures also sent an unnecessary initial wheel for a short, already visible row.
Manual scrolling detaches Tail; a later source refresh adopts Position/Start and legitimately
renews activation/presentation identity. Exact ordinary-preview currentness then dismisses the
old inspection even when marker bounds and bytes are equal. Text visibility and an idle frame
do not prove that a requested placement transition has already been adopted.

For image recovery/original-command/Exit qualification, keep initial Tail placement and wait for
the existing settled delivery/measurement/geometry boundary before capturing preview authority.
Retain intentional navigation tests separately. The original strict recovery tuple, exact source
checks and pixel assertions remain; a temporary paint-observation relaxation was removed because
the actual failure was the whole preview disappearing after legitimate source renewal.

[Composed qualification](../audits/asset-cleanup-qualification.md) records the final passing
receipts and limits. Temporary production diagnostics were removed byte-for-byte. No CAS change,
image decoder workaround, weakened source fence or new runtime authority model was required.
