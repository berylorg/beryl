# Code Save During Staged Source Delivery

The first mounted large Save treated any staged resource candidate at background-write completion
as source retirement. The existing selected-history Source route legitimately stages and measures
its own page publications, so a stable source was cancelled with `Save unavailable: source changed`.
The mounted run `f3cbe150-7c20-44ac-9b74-db8bdd23fa49` exposed this after 5.538 seconds.

The correction retains exact host/source/binding/root/action qualification while separating
ordinary staged publication from invalidation. A completed write consumes its bounded page and
acknowledgement; advancement and final publication election pause until the ordinary candidate
settles, then resume through its existing publication wake. No extra identity field is excluded,
no new loader is added and waiting does not create a per-frame retry loop.

The corrected mounted run `c022a74e-454a-4334-991a-fecbeb8e541a` reached success and verified the exact
large body before a separate test-only capacity assertion failed. Final acceptance must additionally
qualify full residency/disposal and combined behavior. Save's action charge and renderer layout
charge are distinct owned contributions; source length alone is not a bound for retained geometry.
