# Boundary

graph and the shared bounded thread/root picker. Native executable-form choice retains either
Codex App Server binary or Codex CLI binary; folder selection targets its exact invoking runtime.
Cancellation and ordinary rejection restore the original command and flyout facts. Validation,
durable ambiguity and terminal refusal retain the original request and suppress duplicate mutation.

Runtime and root pages publish as a coherent pair. A known Committed or Existing result permits
only the exact named failed page read retry while refresh remains pending. First-runtime admission
prepares and publishes the actual editor and transcript in the original window, preserving its
reservation, selected claim and admission custody. Original widget and worker retirement precede
disposal or accepted failed-home recovery.

Each picker retains the 16 most recently visited collection keys, including current. Returning
refreshes recency; the seventeenth distinct key evicts the least recently visited. Evicted scopes
use owner-supplied initial focus/scroll without activation, and disposal clears instance history.
New Thread scope changes clear search under the feature contract.
