# Generated Media Finalization Architecture

## Boundary And Acceptance

Independent complete-boundary architecture review and independent correction closure accepted the
[generated finalization contract](../systems/image-assets/generated-finalization.md) with its
owning State, Syndic, App, backend, supervisor and GUI contracts. This establishes readiness for
the separate authenticated-source and composed-finalization implementation boundaries. It is not
runtime or implementation acceptance; no source or build/test was changed/run in this architecture
phase.

The feature keeps one generated item/resource identity and exact provider lifecycle. Successful
asset admission is distinct from completion of its fitted rendition. Terminal unavailable media
preserves the provider outcome and history incompleteness; existing terminal-history settlement
can release the ordinary gate without inventing repair authority.

## Existing Seams And Required Ownership

The pinned ingress already excludes inline base64 and retains saved-path ProviderItemV1 facts.
ExecutionSnapshotRecord and ActiveCasTurnRecord retain historical execution provenance. The new
bounded source proof joins that evidence with exact resource/item and immutable source-event/frame
facts; current binding heads and equal runtime generations grant no original file authority.
Ordinary freeze changes current revisions while retaining immutable completion identity.

Existing generated resources already have PendingAsset, Asset and Unavailable backing. Syndic's
asset-only finalized-item invariant and terminal-history settled predicate support the chosen
unavailable/history-incomplete result. Discovery needs the new source primary and monotonic pending
index: resource birth, including unfinished production, receives a never-reused sequence. Finite
high-water sweeps avoid starvation from unrelated capture or new insertions. The closed target
schema is seventy-five primary plus thirty index families; implementation registers no empty
placeholder and preserves existing exact-declaration rejection without migration or home erasure.

HomeStore's admitted sidecar token is generation-bound process authority. State therefore owns a
dedicated durable resource-qualified Prepared record, later Published as the ordinary resource
reference. It creates no fabricated marker/label/projection owner. Exact metadata reuse preserves
committed facts; a new composite participant handles all Asset-domain work. One corresponding
Syndic participant authenticates/resolves the same resource, removes its index entry and applies
only bounded permitted frontier/invalidation work. HomeCommand's one-participant-per-domain rule
is respected; uncertainty retains its original Home coordinator custody.

HomeStore's stream admission uses repeatable digest, write/reuse and comparison passes. Backend
therefore owns one exact open regular file with positional zero-offset cursors, rather than
reopening a path for each factory call. Host uses its original File; WSL requires an explicit V2
original-namespace reader protocol, credential drop, pidfd ownership, bounded frames and positive
reader/namespace closure with channel joins. No replacement runtime, new WSL launch or host UNC
view supplies Linux source proof. These privileged changes require their own native acceptance.

Generated GUI consumption currently lacks prepared lifecycle facts and resource source demands;
its generic binary shell and authored-marker-only adapters do not implement the target. The target
uses one readonly image-marker composition with resource-qualified occurrence identity. Pending
and unavailable states need no byte response; admitted resources enter the existing shared
rendition/original owners. A coherent same-occurrence admission refresh preserves popup and focus;
actual occurrence supersession retains existing anchored closure/fallback behavior.

## Review Corrections And Verification Cuts

The initial draft validated a PNG header before Home admission without binding that header to the
subsequent bytes. A producer could change the same file before every digest pass and publish stale
dimensions. Every source cursor now compares its actual returned header bytes, including the first
digest pass. Physical EOF is read at captured length; clamping an offset cannot hide growth.

The source-proof contract now has explicit AwaitingCompletion and CompletedSource branches. Initial
ownership permits pending or proven lost-source classification; it grants no file/Prepared
authority. Only a successful exact completed source can authorize those operations. Busy/capacity
or pending lookup never proves source loss.

PNG admission is an explicit support set with byte-derived header facts and no raster/rendition
allocation limit. Unsupported generated formats settle that same resource as unavailable; generic
commands for independently admitted JPEG/GIF/SVG originals remain governed by their existing matrix.

Implementation acceptance must qualify native original-source credentials/read/close and repeated
Home admission, then the complete durable preparation/publication/replacement/uncertainty and
visible marker/command outcome. Component proofs, architecture review and readable source alone
do not establish those runtime boundaries.

## Generated Projection Readiness

Operator approved the explicit generated-resource projection repair after composed qualification
exposed the missing non-text producer. Independent review accepted the revised system/history/V7
and App contracts: a tagged generated source and completed set, an explicit stable occurrence,
four existing publication families and fresh lifecycle proof separate from structural identity.
The V2 set is exactly 98 payload bytes and the generated projection is 81 payload bytes; no parser
state or invented content is admitted, and no family is added.

The review required lifecycle freshness and adoption as one complete boundary. Whole bounded-read
Home revision confirmation and existing mutation-observer election fence preparation/publication;
refresh must also compare and adopt changed prepared lifecycle/action facts. Unchanged structural
authority alone cannot suppress that update. These requirements are now explicit in owning
contracts. Readiness establishes implementability, while actual producer, inherited refresh,
stable occurrence and frontier qualification remain implementation acceptance requirements.

Native qualification subsequently confirmed that ordinary complete-only branching excludes a
Pending or Unavailable source tail. The reachable composed sequence therefore tests the original
Pending/admission election and then legal inherited admitted access. It does not claim a native
inherited Pending transition. The presentation comparison and bounded proof fences remain shared
consumer guarantees; no completeness or branch-admission rule was weakened.
