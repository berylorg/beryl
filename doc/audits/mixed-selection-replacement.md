## Qualified Behavior

The widget streams bounded text/object fragments for directed mixed and object-only selections,
including nonresident and same-anchor objects. Evidence restart preserves captured binding,
selection, page identity and independent lane closures. Host mapping authenticates at most two
surviving boundary identities and exact gaps, retains planned positions through replay, and
refuses unrepresentable surviving order before durable admission. Replacement-end and exact
position intents remain distinct; the marked-text exact path and proof-qualified plain-text path
retain their existing semantics.

Storage retains a prefix deletion until the authenticated same-anchor removal run completes.
Separating text survives intermediate removals; the final cut is reproved and completion is joined
once. Persisted tags, layouts, versions and digest inputs are unchanged. Work limits remain
256 structural units, 512 points and 4,194,304 bytes; the reviewed maximum deduplicated acquisition
requires 4,171,588 bytes. Fixed bounded ownership remains authoritative rather than a marker-count
restriction, temporary text, rekey or multiple edit transactions.

Sealed staging submission owns the exact prepared batch and its actual execution outcome. A
resolution error retains original failure, committed receipt, installed handle and local-finalization
state. Exact Source extraction permits retry; exact Target acknowledgement does not execute again.
Cancellation resolves retained external-effect custody before terminal work. Immutable target
sharing avoids payload duplication. Real failed-generation capability retention and source review
qualify one-time finalization custody; no fabricated healthy-capability failure is claimed.

MutationPredecessor reads preserve the widget's captured predecessor binding while deriving the
private SDK descriptor from the same operation's acknowledged typed session/head and canonical
enriched begin. Full operation, predecessor and staging-receipt correspondence remain mandatory.
Unresolved flights grant no refreshed descriptor; ordinary SDK stale-session guards remain strict.

Private borrowed validators and separated dispatch frames remove repeated fixed aggregate copies
from the deferred marker chain. Public records/getters, exact comparisons, transition order and
the acquisition ledger remain unchanged. Native clearing uses the ordinary WinRT worker stack.
