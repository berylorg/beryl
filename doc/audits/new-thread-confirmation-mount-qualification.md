## Boundary

The New Thread secondary segment opens the bounded confirmed-selection runtime/root picker.
Each opening starts with all runtimes, empty search and no pending root. Scope changes clear
search and preserve selection only while its exact root remains eligible in that scope.
Confirm uses the accepted atomic same-window acquisition and saved predecessor capability.
It suppresses duplicate admission and publishes the accepted claim, remembered root, editor
and transcript coherently in the invoking window.

Interrupted confirmation has a distinct failed-home handoff. Original save publication settles
before original claim outcome classification through fresh candidate access. Never-admitted or
proven-noncommit operations restore the exact prior editor, text, selection and history. A committed
operation restores its exact accepted target without another claim command or predecessor save.
Completed disposal, GUI release and partial successor abandonment retain their original outcomes.
Terminal uncertainty remains unavailable with original custody intact.

Prepared replacement graph Drop returns the actual graph, candidate, editor and original creation
custody to the process owner. Partial fresh-mount cancellation drains and disposes its actual
replacement before restoring the original gated mount. Process selection exclusion releases only
inside successful coherent reopening; a competing Home election preserves the same fence and lease.
The production supervisor resumes the original typed creation through its retained graph,
candidate or published-service state, including proven-prior conversion and cancellation.
Original delivered Page cleanup uses a source-owned cleanup-only capsule in the common window
draft, allowing actual old-driver completion without releasing the protected Page early. The
original release effects and ledger acknowledgements still precede coherent reopening.
