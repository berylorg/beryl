# Ordinary Accepted-Input Composer History

Status: accepted after independent semantic/lifetime review.

## Implemented Boundary

Focused Alt+Up/Alt+Down browse exact accepted inputs in the current window and conversation.
The bounded window owner survives selection and revalidated same-home recovery, collapses
consecutive equal inputs, evicts eligible entries/scopes and releases history on window close.
Capture occurs at exact acceptance, independently of successor presentation and detached settlement.

Recall reconstructs destination-scoped trees from authenticated sealed source pages. The original
first-acceptance command writes its complete request/result into an acceptance-purpose disposal
receipt in the existing session family. Repeated build/progress/settlement records retain compact
receipt references and authenticate the original receipt wherever source authority is consumed.
The existing 103-family Home declaration, record bounds and ordinary/replacement bytes remain intact.
The [source-authority lesson](../failures/composer-recall-source-authority.md) preserves the rejected
full-receipt embedding and follow-on candidate-provenance correction.

Recall and forward restoration append ordinary undoable transitions and clear Redo. A same-session
opaque checkpoint restores the pre-browse root, caret and directed selection after intervening
edits or Undo eviction. Marker identity, labels and exact assets use distinct bounded recall proofs.
Thread-edit mode and exhausted directions are no-ops. Pending work preserves the coherent editor,
fences mutations/submission and supports Escape cancellation. Definite refusal releases staging;
ambiguous and committed-later-failure outcomes retain original custody through fresh recovery.

The actual composer owner routes keys and cancellation off GPUI; host/slot adoption and source
realization precede cursor publication. Initial, threadless, first-conversation and recovery shell
paths share the window owner. Final root teardown closes it and ignores later accepted deliveries.
